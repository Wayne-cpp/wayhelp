### 关键产出
- `pyproject.toml`:`[dependency-groups]` 拆 topic-data(numpy/scikit-learn/scikit-multilearn/opencc)/ dev(`{include-group="topic-data"}` + pytest)/ train(topic-data + torch/transformers/datasets/onnx/onnxruntime/optimum[onnx]);末尾追加 `[[tool.uv.index]] pytorch-cpu(https://download.pytorch.org/whl/cpu, explicit=true)` + `[tool.uv.sources] torch = [{index, marker="sys_platform=='linux'"}]`
- Context7 核实结论(/astral-sh/uv 当前文档):① PEP 735 `{include-group = "name"}` 表项语法属实,且 `dev` 组被 uv 特殊对待、`uv run`/`uv sync` 默认装 dev → train 组不进默认闭包即默认无 torch;② index `explicit=true` 语义属实:该索引只服务 `tool.uv.sources` 显式映射到它的包,文档示例恰为 pytorch CPU 源 + 平台 marker 列表写法。实跑吻合:lock 出 `torch v2.14.1+cpu`(linux marker 走 pytorch-cpu)与 `v2.14.1`(非 linux 走 PyPI)双条目;默认 sync 后 `uv pip list` 无 torch/transformers/onnx
