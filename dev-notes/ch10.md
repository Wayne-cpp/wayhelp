### 关键产出
- `plan_augmentation(train_records, all_texts, target_ratio=1.3)`:need = max(0, round(len × ratio) − len),取前 need 条为 parent 计划,每 parent ≤1 派生(all_texts 形参为计划钉死的接口形状,计划草案本体即未在 plan 阶段使用)
- `apply_augmentation(train_records, variants, all_texts, assignment)`:parent 须在 train_records 且 assignment == "train"(val/test 样本不得被增强);变体文本 strip 后为空或命中三份现有文本集合 → 丢弃;派生记录 sample_id=`aug-<parent>`,继承 source/source_group_id/labels/intended_labels,parent_id 记录
- `llm_rewrite(plan, llm, batch_size=20)`:镜像 llm_polish 的三重 ID 校验(sorted 集合比对/条数/重复);返回 (variants, failed_batches)
- `_ChatRewriter` 适配器(仅 CLI):同义词替换/语序调整/语气词增删,保持原意与全部诉求、不增删信息、不修正错别字,要求与原文至少差两个字(原样返回会与既有文本撞车被丢)
- CLI(`--manifest` 默认 data/topic_classifier/split_manifest.json / `--target-ratio 1.3` / `--batch-size 20`):manifest 只含 sample_id/split/content_hash 无文本 → 从 manifest 同目录读 train/val/test.jsonl;幂等重跑——先剥离既有派生样本(parent_id 非 None)从基线重算,防 aug- 套 aug-;原地改写 train.jsonl(train.py 只读该文件),val/test 不动;打印基线/计划/失败批/丢弃/前后条数
